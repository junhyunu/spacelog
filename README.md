# spaceLog

기록(글 · 링크 · 파일 · 이미지)을 "별"로, 카테고리를 "행성"으로 보여 주는 개인용 우주 아카이브예요. 내 컴퓨터에서만 도는 로컬 웹 앱이고, 우주 화면에 파일을 끌어다 놓거나 "기록하기"를 눌러 별을 띄워요.

## 필요한 것

- Node.js 22 이상

## 설치

```
npm install
```

## 실행

**쓸 때**

```
npm run build
npm start
```

브라우저에서 <http://127.0.0.1:4747> 을 열어요. 서버 하나가 화면과 데이터를 함께 제공해요.

**개발할 때**

```
npm run dev
```

<http://localhost:5173> 을 열어요. 화면(Vite)과 서버가 함께 뜨고, 코드를 고치면 바로 반영돼요.

## 데이터가 저장되는 곳

기본 위치는 사용자 홈 폴더의 `spaceLog` 폴더(`~/spaceLog`)예요.

| 이름 | 내용 |
|---|---|
| `spacelog.db` | 행성과 별의 기록 |
| `vault/` | 끌어다 놓은 파일의 복사본 |
| `thumbs/` | 이미지 축소본 |
| `rag/` | 챗봇이 읽어 둔 색인(챗봇을 켰을 때만) |

환경 변수로 바꿀 수 있어요.

| 변수 | 뜻 | 기본값 |
|---|---|---|
| `SPACELOG_DATA` | 데이터 폴더 경로 | `~/spaceLog` |
| `PORT` | 서버 포트 | `4747` |
| `SPACELOG_RAG_PORT` | 챗봇 서버(파이썬) 포트 | `4748` |

## 백업

서버를 끈 다음 데이터 폴더를 통째로 복사해요. 되돌릴 때는 서버를 끈 상태에서 그 폴더를 같은 자리에 다시 넣어요.

## 끄는 법과 주의할 점

- 서버를 켠 터미널에서 `Ctrl+C`를 누르면 꺼져요.
- `npm run dev`도 실제 데이터 폴더(`~/spaceLog`)를 써요. 연습용으로 쓰려면 `SPACELOG_DATA`로 다른 폴더를 지정해 주세요.
- 같은 데이터 폴더로 서버를 두 개 띄우지 마세요.
- 백업을 되돌릴 때는 `spacelog.db`와 `vault/`, `thumbs/`를 반드시 같은 시점의 것으로 함께 되돌려 주세요. 한쪽만 되돌리면 기록과 파일이 어긋나요.
- 기록에 연결되지 않은 보관함 파일은 지우지 않고 `orphans/` 폴더로 옮겨 둬요. 필요 없으면 직접 지우면 돼요.

## 챗봇(2차)

별을 읽어 두었다가 "찾아 줘 · 뭐라고 적었더라 · 요약해 줘" 같은 질문에 답해요. 답에는 근거가 된 별이 출처 카드로 붙어요. 기본은 꺼져 있고, 켜기 전에는 OpenAI로 아무것도 보내지 않아요.

**필요한 것**

- 파이썬 3.11 이상(설치할 때 "Add python.exe to PATH" 선택)
- OpenAI API 키

**설치**

```
npm run rag:setup
```

`rag/.venv`를 만들고 필요한 패키지를 설치해요. 한 번만 하면 돼요.

프로젝트 폴더 맨 위에 `.env` 파일을 만들어요. 이 파일은 git에 올라가지 않아요.

```
OPENAI_API_KEY=sk-...여기에-내-키...
OPENAI_MODEL=gpt-4o-mini
OPENAI_EMBED_MODEL=text-embedding-3-small
```

`OPENAI_MODEL`과 `OPENAI_EMBED_MODEL`은 비워 두면 위의 값을 써요. 키는 파이썬 쪽만 읽고, 화면이나 Node 서버로는 오가지 않아요. `OPENAI_TEMPERATURE`는 넣지 않는 것을 권해요(일부 모델은 기본값 외의 temperature를 받지 않아요). 수업처럼 0으로 두고 싶으면 `OPENAI_TEMPERATURE=0`을 더하세요.

**켜는 법**

1. 지금처럼 `npm run dev` 또는 `npm start`로 서버를 켜요. Node 서버가 챗봇 서버(파이썬, `127.0.0.1:4748`)를 함께 켜고, 끌 때 같이 꺼요.
2. 화면 오른쪽 아래 원자 모양 버튼을 눌러요.
3. 안내를 읽고, 챗봇이 읽지 않을 행성을 체크한 뒤 "켜기"를 눌러요. 그때부터 별을 읽기 시작해요. 설정 탭에서 읽은 별 수를 볼 수 있어요.

나중에 설정 탭에서 끄거나, 행성을 빼거나 다시 넣을 수 있어요. 행성을 빼면 그 행성의 읽어 둔 내용은 바로 지워요.

**OpenAI로 보내지는 것**

- 색인할 내용: 빼 두지 않은 행성의 별 제목 · 글 · 메모 · 행성 이름, 링크 제목 · 주소, 글자를 읽을 수 있는 첨부 파일의 본문
- 질문할 때: 질문, 지금 열린 행성 · 별 같은 화면 맥락, 오늘 날짜, 질문과 관련된 기록 조각
- 같은 대화의 최근 메시지 몇 개(이어 묻기용). 나중에 행성을 빼도 그 전에 같은 대화에서 오간 내용은 다시 보내질 수 있어요. 새 대화를 시작하면 보내지지 않아요.

챗봇을 끄면 색인과 질문을 모두 멈춰요. 읽어 둔 색인 파일(`<데이터 폴더>/rag/index.json`)은 내 PC에 남아요.

**비용**

OpenAI 요금은 키 주인에게 나와요. 처음 켤 때 모든 별을 한 번 읽고(임베딩), 그 뒤에는 바뀐 별만 다시 읽어요. 질문 하나에는 채팅 모델 요청이 보통 두 번(질문 풀기 · 답하기) 들어가요. 기본 모델 기준으로 개인 기록 정도면 큰 비용은 아니지만, 설정 탭의 "이번 달 요청 수"로 확인해 주세요.

**테스트**

```
npm run rag:test
```

OpenAI를 부르지 않는 가짜 모델로 돌아요.

**문제가 생기면**

| 증상 | 해결 |
|---|---|
| `npm run rag:setup`이 "파이썬 3.11 이상을 찾지 못했어요" | 파이썬을 설치하고 PATH에 넣은 뒤 터미널을 다시 열어 다시 실행해요 |
| 챗봇 창에 "챗봇을 준비하지 못했어요" | `npm run rag:setup`을 아직 안 했거나 실패한 거예요. 다시 실행해요 |
| "OpenAI 키가 없어요" | `.env`에 `OPENAI_API_KEY`를 넣고 서버를 다시 켜요 |
| "챗봇 서버 포트를 다른 프로그램이 쓰고 있어요" | 다른 spaceLog를 닫거나, `SPACELOG_RAG_PORT`로 다른 포트를 정해요 |
| `rag/.venv`가 깨졌다는 메시지, 파이썬을 지우거나 옮긴 뒤 | `rag/.venv` 폴더를 지우고 `npm run rag:setup`을 다시 실행해요 |

```
npm test
```

## 알려진 제한

- 한 사람이 한 컴퓨터에서 쓰는 앱이에요. 로그인과 기기 사이 동기화는 없어요.
- 서버는 `127.0.0.1`에만 열려요. 다른 기기에서는 접속할 수 없어요.
- 파일과 기록은 내 PC에 있고, 챗봇을 켜면 질문에 필요한 내용과 색인할 내용만 OpenAI로 보내져요. 그 밖에 밖으로 나가는 요청은 링크를 저장할 때 그 주소의 제목을 가져오는 것뿐이에요. 3초 안에 못 가져오면 주소를 제목으로 써요.
- 파일 하나가 500MB를 넘으면 담을 수 없어요.
- "원본 열기"는 안전한 종류의 파일만 바로 열어요. 실행 파일 같은 나머지는 열지 않고 폴더에서 보여 줘요.
- 열리는 것은 보관함(`vault/`)의 복사본이에요. 원본 파일은 건드리지 않아요.
- 챗봇은 이미지 속 글자와 스캔한 PDF를 읽지 못해요. 파일 이름만 읽어요.
- 챗봇은 hwp 파일의 본문을 읽지 못하고 이름만 읽어요(hwpx는 본문을 읽어요).
- 챗봇은 링크한 페이지의 본문을 읽지 않아요. 링크 제목과 주소만 읽어요.
- 챗봇은 기록을 읽기만 해요. 별을 만들거나 고치거나 지우지 않아요. 답을 별로 남기려면 "별로 저장"을 눌러요.
- 탐사선은 들어 있지 않아요.
