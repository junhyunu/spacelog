# spaceLog

기록(글 · 링크 · 파일 · 이미지)을 "별"로, 카테고리를 "행성"으로 보여 주는 개인용 우주 아카이브예요. 내 컴퓨터에서만 도는 로컬 웹 앱이고, 우주 화면에 파일을 끌어다 놓거나 "기록하기"를 눌러 별을 띄워요.

## 필요한 것

- Node.js 22 이상

## 설치

```
npm install
```

## 실행

**쓸 때**

```
npm run build
npm start
```

브라우저에서 <http://127.0.0.1:4747> 을 열어요. 서버 하나가 화면과 데이터를 함께 제공해요.

**개발할 때**

```
npm run dev
```

<http://localhost:5173> 을 열어요. 화면(Vite)과 서버가 함께 뜨고, 코드를 고치면 바로 반영돼요.

## 데이터가 저장되는 곳

기본 위치는 사용자 홈 폴더의 `spaceLog` 폴더(`~/spaceLog`)예요.

| 이름 | 내용 |
|---|---|
| `spacelog.db` | 행성과 별의 기록 |
| `vault/` | 끌어다 놓은 파일의 복사본 |
| `thumbs/` | 이미지 축소본 |

환경 변수로 바꿀 수 있어요.

| 변수 | 뜻 | 기본값 |
|---|---|---|
| `SPACELOG_DATA` | 데이터 폴더 경로 | `~/spaceLog` |
| `PORT` | 서버 포트 | `4747` |

## 백업

서버를 끈 다음 데이터 폴더를 통째로 복사해요. 되돌릴 때는 서버를 끈 상태에서 그 폴더를 같은 자리에 다시 넣어요.

## 끄는 법과 주의할 점

- 서버를 켠 터미널에서 `Ctrl+C`를 누르면 꺼져요.
- `npm run dev`도 실제 데이터 폴더(`~/spaceLog`)를 써요. 연습용으로 쓰려면 `SPACELOG_DATA`로 다른 폴더를 지정해 주세요.
- 같은 데이터 폴더로 서버를 두 개 띄우지 마세요.
- 백업을 되돌릴 때는 `spacelog.db`와 `vault/`, `thumbs/`를 반드시 같은 시점의 것으로 함께 되돌려 주세요. 한쪽만 되돌리면 기록과 파일이 어긋나요.
- 기록에 연결되지 않은 보관함 파일은 지우지 않고 `orphans/` 폴더로 옮겨 둬요. 필요 없으면 직접 지우면 돼요.

## 알려진 제한

- 한 사람이 한 컴퓨터에서 쓰는 앱이에요. 로그인과 기기 사이 동기화는 없어요.
- 서버는 `127.0.0.1`에만 열려요. 다른 기기에서는 접속할 수 없어요.
- 밖으로 나가는 요청은 링크를 저장할 때 그 주소의 제목을 가져오는 것 하나뿐이에요. 3초 안에 못 가져오면 주소를 제목으로 써요.
- 파일 하나가 500MB를 넘으면 담을 수 없어요.
- "원본 열기"는 안전한 종류의 파일만 바로 열어요. 실행 파일 같은 나머지는 열지 않고 폴더에서 보여 줘요.
- 열리는 것은 보관함(`vault/`)의 복사본이에요. 원본 파일은 건드리지 않아요.
- 탐사선과 챗봇은 1차에 들어 있지 않아요.
