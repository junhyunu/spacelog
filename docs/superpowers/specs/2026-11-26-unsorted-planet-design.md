# 미분류 행성 설계

2026-11-26 대화에서 합의한 내용. 시안: https://claude.ai/artifact/2ZPJkJYhd6MjaRB7eDR9Tu (v2, 먼지 크기 B)

## 목적

분류를 귀찮아하는 사용자를 위해, 행성을 고르지 않고 저장한 기록이 모이는 기본 행성을 둔다. 쌓인 기록은 나중에 여러 개를 골라 한 번에 다른 행성으로 옮긴다.

## 결정

1. **항상 있는 행성 하나.** id `unsorted`, 이름 `미분류`, 설명 `고르지 않고 저장한 기록`. 모든 DB(새 DB · 기존 DB)에 켤 때 없으면 만든다.
2. **잠금.** 이름 · 설명 · 모습을 바꿀 수 없고, 지울 수 없고, 다른 행성으로 합칠 수 없다(다른 행성을 미분류로 합치거나, 다른 행성을 지울 때 별을 미분류로 옮기는 것은 된다). 화면에는 꾸미기 · 지우기 · 합치기 메뉴가 없고, 패널에 "기본 행성이라 이름을 바꾸거나 지울 수 없어요" 한 줄을 보인다.
3. **자리.** 행성 자리 번호(slot) `-1`. 우주 좌표 `[14, 3, 0]`(출발점 오른쪽 앞). 다른 행성 자리(0~9, 바깥 고리)와 따로라 행성을 추가 · 삭제해도 다른 행성 자리는 그대로다. 목록에서는 늘 맨 위(서버가 slot 순으로 준다).
4. **모습.** 어두운 줄무늬 구(툰 셰이딩 + 잉크 외곽선). 장식 · 깃발 · 고리 없음. 크기 고정(반지름 4.2, 별 수로 커지지 않음).
5. **먼지.** 미분류의 별 하나 = 하얀 먼지 한 알. 장식 먼지 없음. 크기 **1.3**(월드 단위, 원근에 따라 작아짐). 행성을 기울어진 납작한 띠로 돈다(궤도 반지름 6.0~8.6). 최근 것부터 **300알**까지 그린다. 0개면 먼지 없이 행성만.
6. **기본 선택 순서(저장 창).** 열린 행성 패널의 행성 → 미분류. "마지막으로 저장한 행성"은 쓰지 않는다.
7. **별 · 먼지 누르기 없음.** 우주에서 별 · 먼지는 클릭 대상이 아니다. 그 자리를 눌러도 뒤의 행성이 눌린다. 별 상세는 패널 목록에서 연다.
8. **일괄 이동.** 우주 행성 패널(모든 행성)에 "여러 개 고르기" → 체크칸 → 아래 바 "N개 골랐어요 · 행성 옮기기" → 확인 창(옮길 행성 고르기) → 서버가 한 번에 옮김 → 토스트 "N개를 '행성'(으)로 옮겼어요". 우주에서는 먼지가 그 행성으로 날아가 별이 된다(기존 "옮긴 별이 날아가는" 동작 그대로).

9. **홈 목록도 일괄 이동.** 홈 별 목록에 우주 패널과 같은 고르기 모드 · 문구 · 확인 창을 둔다(같은 공통 함수 사용).
10. **공통 표시.** 행성 색을 쓰는 모든 곳에서 미분류는 슬레이트색(`#4c5b6b`, 진한 색 `#26303c`). DB의 color_index(1, 주황)는 화면에 쓰지 않는다. 행성이 나오는 모든 목록 · 선택 칸에서 미분류는 맨 위.
